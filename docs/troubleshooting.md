# Ошибки и решения

## Получилось меньше товаров, чем запрошено { #fewer-results }

`--limit` задаёт максимум уникальных товаров, а `--max-pages` ограничивает число прочитанных страниц. По умолчанию команда читает до 10 страниц. Если витрина отдаёт по 8 уникальных карточек на страницу, при `--limit 100` можно получить 80.

```sh
uv run ozoner "техника" --limit 100 --max-pages 20 --log-level DEBUG
```

`DEBUG` покажет номера страниц. Если выдача закончилась или [локальная проверка цены](filters.md#local-price) исключила часть товаров, строк всё равно может оказаться меньше. См. [параметры CLI](cli.md#options).

## Ozon вернул HTTP 403 { #http-403 }

Витрина может отклонить запрос к поиску, категории или карточке. Успешный поиск не гарантирует доступ к детальной странице товара. В Python проверяйте [`OzonHTTPError.status`](reference.md#ozoner.OzonHTTPError.status). В CLI включите [логирование](cli.md#logging), чтобы увидеть, на каком шаге произошёл отказ.

```python
from ozoner import OzonClient, OzonHTTPError

try:
    details = OzonClient().get_product(123456789)
except OzonHTTPError as error:
    print(error.status)
```

## Chrome не запускается { #chrome }

Проверьте, что Google Chrome установлен. Если он находится в нестандартном каталоге, укажите путь через [`--chrome`](cli.md#options) в CLI или [`OzonClient(chrome_path=...)`](reference.md#ozoner.OzonClient) в Python. [Установка и первый запрос](start.md).

## CSV не появился { #csv }

CLI завершает работу с ошибкой, если не получил товары или не смог записать файл. Убедитесь, что каталог назначения существует и файл не открыт в программе, которая блокирует запись. При сбое получения данных прежний CSV сохраняется. [Формат CSV и команды экспорта](cli.md).

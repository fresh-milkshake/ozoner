# План тестирования и исправления парсера

## Цель

Протестировать улучшенный парсер, выявить проблемы в результатах CSV и исправить их, повторяя цикл до идеального результата.

## Критерии успеха .

1. Названия товаров - реальные названия, без промо-текстов ("Распродажа", "баллов за отзыв" и т.д.)
2. Описания - заполнены для большинства товаров
3. Цены - корректные значения (не 0.00, не огромные числа)
4. Заполненные поля - категория, бренд, продавец, SKU где возможно

## Шаги тестирования

### Шаг 1: Запуск тестового скрипта

- Запустить `go run test/test_technika_csv.go`
- Дождаться завершения (может занять 5-15 минут)
- Проверить создание файла `technika_products.csv`

### Шаг 2: Анализ результатов

- Прочитать CSV файл
- Проверить каждую строку на:
- Наличие промо-текстов в названиях
- Наличие описаний
- Корректность цен (не 0, не огромные числа)
- Заполненность полей (категория, бренд, продавец)

### Шаг 3: Выявление проблем

- Если названия содержат промо-тексты:
- Проверить работу `IsPromoText` в `internal/parser/helpers.go`
- Улучшить фильтрацию в `parseProductItem` и `parseProductsFromHTML`
- Добавить больше паттернов промо-текстов

- Если описания отсутствуют:
- Проверить извлечение описания в `ParseProduct` (`internal/parser/product.go`)
- Улучшить поиск описания в widgetStates
- Проверить HTML парсинг описания в `parseProductFromHTML`

- Если цены некорректные:
- Проверить `ValidatePrice` и `CleanPriceText` в `internal/parser/helpers.go`
- Улучшить парсинг цен из JSON и HTML
- Добавить обработку цен в копейках

- Если поля пустые:
- Улучшить глубокий поиск в widgetStates
- Расширить список ключей для поиска категории, бренда, продавца

### Шаг 4: Внесение исправлений

- Внести правки в соответствующие файлы
- Убедиться, что код компилируется (`go build ./...`)

### Шаг 5: Повторное тестирование

- Удалить старый CSV файл (опционально)
- Запустить тест снова
- Проанализировать результаты

### Шаг 6: Итерация

- Повторять шаги 2-5 до достижения идеального результата
- Максимум 5 итераций для предотвращения бесконечного цикла

## Файлы для проверки и изменения

- `internal/parser/helpers.go` - функции фильтрации и валидации
- `internal/parser/search.go` - парсинг результатов поиска
- `internal/parser/product.go` - парсинг детальной информации о товаре
- `pkg/ozoner/ozoner.go` - HTML парсинг и основная логика

## Ожидаемое время

- Первый запуск теста: 5-15 минут
- Каждая итерация исправлений: 2-5 минут
- Всего: до 1 часа при необходимости нескольких итераций

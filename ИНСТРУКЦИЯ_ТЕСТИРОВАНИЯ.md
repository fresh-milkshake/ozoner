## Что делает тест

1. **Создает клиент** с настройками по умолчанию
2. **Ищет товары** по запросу "техника"
3. **Собирает 40 товаров** с нескольких страниц (если доступно)
4. **Получает детальную информацию** для каждого товара
5. **Создает CSV файл** `technika_products.csv` с полной информацией

## Структура CSV файла

CSV файл содержит следующие колонки (разделитель `;`):

| Колонка | Описание |
|---------|----------|
| ID | Уникальный идентификатор товара |
| Название | Название товара |
| Описание | Полное описание товара |
| Цена | Текущая цена |
| Старая_цена | Старая цена (если есть скидка) |
| Валюта | Валюта (обычно RUB) |
| Рейтинг | Рейтинг товара |
| Отзывов | Количество отзывов |
| SKU | Артикул товара |
| Категория | Категория товара |
| Бренд | Бренд товара |
| ID_продавца | ID продавца |
| Название_продавца | Название продавца |
| В_наличии | Наличие товара (true/false) |
| URL | Ссылка на товар |
| Изображения | Список изображений (разделены " \| ") |
| Атрибуты | Характеристики товара (форматированные) |

## Возможные проблемы и решения

### Проблема: Ошибка 403 (Forbidden)
**Причина:** Ozon.ru блокирует автоматические запросы

**Решение:** 
1. Скрипт автоматически попробует использовать браузерный клиент
2. Если браузерный клиент недоступен, установите Chrome/Chromium
3. Или используйте прокси

### Проблема: Товары не найдены
**Причина:** 
- Изменилась структура API Ozon
- Антибот-защита блокирует запросы
- Проблемы с сетью

**Решение:**
- Проверьте интернет-соединение
- Попробуйте запустить с браузерным клиентом
- Увеличьте таймауты в коде

### Проблема: Таймауты
**Решение:** Увеличьте таймауты в коде:
```go
config.Timeout = 90 * time.Second  // Вместо 45
ctx, cancel := context.WithTimeout(context.Background(), 15*time.Minute)  // Вместо 10
```
